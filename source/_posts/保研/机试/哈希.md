### 哈希

哈希表内部无序，查找/插入/删除的平均复杂度均为$O(1)$。

#### 常用容器

| **容器**             | **键** | **键值对** | **头文件**        |
| :------------------- | :----- | :--------- | :---------------- |
| `unordered_set`      | 唯一   | 仅键       | `<unordered_set>` |
| `unordered_multiset` | 不唯一 | 仅键       | `<unordered_set>` |
| `unordered_map`      | 唯一   | 键→值      | `<unordered_map>` |
| `unordered_multimap` | 不唯一 | 键→值      | `<unordered_map>` |

#### 常用函数

| **函数**                 | **说明**                                                 |
| :----------------------- | :------------------------------------------------------- |
| `insert({k,v})`          | 插入键值对                                               |
| `emplace(k, v...)`       | 原地构造，更高效                                         |
| `operator[k]`            | 返回 key 对应值的引用，不存在则插入默认值（仅 map）      |
| `at(k)`                  | 返回 key 对应值的引用，不存在抛 `out_of_range`（仅 map） |
| `find(k)`                | 返回迭代器，未找到返回 `end()`                           |
| `count(k)`               | 返回 key 出现次数（map/set 为0或1；multi 为实际个数）    |
| `erase(it)` / `erase(k)` | 删除单个元素或所有等于 k 的元素                          |
| `clear()`                | 清空                                                     |
| `size()` / `empty()`     | 容量                                                     |
| `reserve(n)`             | 预留空间避免多次 rehash                                  |

### 红黑树

内部有序，且默认升序，查找/插入/删除的平均复杂度均为$O(long n)$。

#### 常用容器

| **容器**   | **键唯一** | **键值对** | **头文件** |
| :--------- | :--------- | :--------- | :--------- |
| `set`      | 唯一       | 仅键       | `<set>`    |
| `multiset` | 不唯一     | 仅键       | `<set>`    |
| `map`      | 唯一       | 键→值      | `<map>`    |
| `multimap` | 不唯一     | 键→值      | `<map>`    |

#### 常用函数

与哈希类似，但有序容器独有下面两个函数。

| **函数**         | **说明**                 |
| :--------------- | :----------------------- |
| `lower_bound(k)` | 返回第一个 >= k 的迭代器 |
| `upper_bound(k)` | 返回第一个 > k 的迭代器  |
